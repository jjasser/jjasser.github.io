THE PERSON BEHIND THE NOTES

I’m Jacob.

An AI Security Engineer with a background in cloud security engineering and security architecture.

I work across LLMs, RAG pipelines, agents, and the infrastructure and services that support them. I follow how systems are built, where security risks emerge, and how layered protections can address them. This blog shares practical projects and lessons from that work.

01 / FOCUS

What I work on

AI application & agent security

Prompt injection, sensitive data exposure, tool permissions, and trust boundaries between models, external content, and services.

Adversarial testing & guardrails

Testing systems, investigating bypasses, and comparing results before and after introducing a control.

Cloud security & automation

Event-driven remediation and automated guardrails that turn security requirements into working controls.

Security architecture

Understanding how systems fit together, identifying attack paths, and choosing controls for the underlying risk.
