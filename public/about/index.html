I'm Jacob.

AI Security Engineer · Cloud Security · Security Automation

AI Security Engineer · Cloud Security · Security Automation

I’m Jacob, an AI Security Engineer with a background in cloud security engineering, and security architecture.

I take a holistic approach to AI security, working across LLMs, RAG pipelines, agentic systems, and the infrastructure and services that support them. I embed myself across these layers to understand how systems are built, where security risks emerge, and how layered protections can address them.

This blog is where I share practical projects, technical insights, and lessons from securing AI systems—from architecture and implementation to testing and ongoing operation.

What I work on

  • AI application & agent security. Exploring prompt injection, sensitive data exposure, tool permissions, and the trust boundaries between models, external content, and connected services.
  • Adversarial testing & guardrails. Testing AI systems, investigating bypasses, and comparing results before and after introducing a control. I’m particularly interested in what defenses actually prevent and where they fall short.
  • Cloud security & automation. Building on experience with event-driven remediation, and automated guardrails that turn security requirements into working controls.
  • Security architecture. Understanding how a system fits together, identifying meaningful attack paths, and choosing controls that address the underlying risk.
